# Mirrors requirements.txt / pyproject.toml's [project.dependencies], plus
# pyproject.toml's optional `postgres` extra -- the container image supports
# BOTH the SQLite and PostgreSQL backends in one image, selected at runtime
# by whether NEXUS_DATABASE_URL is set (see runtime.create_runtime). This
# keeps the image environment-driven rather than requiring two separate
# builds for the two backends.

# development. It is not imported by any application module (api.py,
# main.py, runtime.py, tool_policy.py, ...) and is not needed to run the
# API, so it is left out of the production image to keep it minimal.
#
# Version floors are kept identical to requirements.txt / pyproject.toml's
# postgres extra -- update all three together if a floor changes.
